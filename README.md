# 🛡️ Sentinel P

**A real-time system & security monitoring dashboard for your desktop.**

Sentinel Py runs quietly in the background and gives you a live, browser-based control panel for your PC — CPU, RAM, network activity, running processes, startup items, firewall status, and a full one-click security audit, all backed by real data pulled directly from your machine.

## What is Sentinel Py?

Sentinel Py is a lightweight, self-hosted monitoring tool that turns your browser into a live security & performance dashboard for your own computer. It watches your system in real time and surfaces anything worth knowing about: unusual processes, exposed network ports, weak firewall settings, unexpected startup entries, and suspicious file activity.

Everything runs **locally on your machine**. No data is ever sent to a server, tracked, or shared — the dashboard you see is generated by a small program running on your own PC and displayed in your own browser.

## What it does

| Area | What Sentinel Py shows you |
|---|---|
| 📊 **System vitals** | Live CPU, RAM, disk usage, and uptime, visualized with real-time charts |
| 🧠 **Process manager** | Every running process, with the ability to terminate any of them in one click |
| 🌐 **Network monitor** | Active connections and listening ports, with automatic flags on risky ports (RDP, SMB, Telnet, etc.) |
| 🔥 **Firewall status** | Whether your system firewall is active, checked natively per OS |
| 🧩 **Startup / persistence scan** | Programs configured to auto-run at boot (Windows registry Run keys) — a common malware persistence technique |
| 🗂️ **File activity monitor** | Live tracking of new/changed/deleted files in your `Downloads` and `Documents` folders |
| 🔎 **One-click security audit** | Combines process, persistence, network, and hosts-file checks into a single scan |
| 📄 **PDF reports** | Export a full audit as a clean, shareable PDF |
| 🚨 **Threat feed** | A rolling log of alerts as they're detected |

## How it works

Sentinel Py has two parts:

1. **A local backend** (`app.py`) — a small Python/Flask server that reads live data from your operating system using libraries like `psutil` and `watchdog`, and exposes it as a local API.
2. **A dashboard frontend** (`dash.html`) — a single HTML page that queries that local API and renders everything as live charts, tables, and stats.

When you run Sentinel Py, it starts the backend on `127.0.0.1` (your own machine only) and automatically opens the dashboard in your default browser. Because it only reads from — and binds to — the machine it's running on, whatever you see is *your* system, in real time.


## Tech stack

- **Backend:** Python, Flask, `psutil`, `watchdog`, `reportlab`
- **Frontend:** Vanilla HTML/CSS/JS, Chart.js, Feather Icons
- **Packaging:** PyInstaller

## Privacy & security

- Sentinel Py binds only to `127.0.0.1` — it is not reachable from other devices on your network.
- No data is ever transmitted anywhere; everything is read and displayed locally.
